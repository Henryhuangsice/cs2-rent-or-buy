# 租还是买：CS2 饰品决策助手

[在线试用](https://henryhuangsice.github.io/cs2-rent-or-buy/)（离线规则模式，不上传输入）

输入“折刀多普勒想玩个周末，预算800”，比较**租后归还 / 买后卖 / 买断 / 直接买**的真实成本，并给出平衡点、规则依据和运行轨迹。竞品与风控分析见 [docs/竞品拆解.md](docs/竞品拆解.md)。

## Agent harness

```
输入 → GUARD → PARSE(LLM) → 校验 + 交叉核对 ─冲突/缺信息→ 追问
                  └失败→ 规则解析      ↓
       输出 ← VERIFY ← EXPLAIN(LLM) ← 确定性工具(算钱/查规则)
                └不通过→ 重试一次 → 模板
```

- **LLM 不算钱**：金额与结论全部来自 `src/engine.js`；解释中每个数字都必须能在工具结果中找到，首句结论必须一致。
- **不猜**：缺天数、磨损有歧义、模型与规则解析冲突时追问。
- **有预算**：每次最多 3 次 LLM 调用，单次超时 15 秒；模型全部失效仍能给出结果。
- **可回放**：每一步写入轨迹，页面底部可看。
- **守卫先行**：索要凭证、滥用、涨跌预测在调用模型前拦截。

## 运行（无依赖）

```bash
python3 -m http.server 5178   # 打开 http://localhost:5178
npm test
npm run eval
npm run ask -- "折刀租10天"
```

接入大模型（任意 OpenAI 兼容接口）：设置环境变量 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY` 后再运行 `ask` 或 `eval`。

## 评测（2026-11-23）

| 项目 | 结果 |
|---|---|
| 开发集，离线规则 | 首跑 34/40，修复后 40/40 |
| 留出集，离线规则，首跑，未据此调参 | **16/20** |
| 6 类坏输出故障注入（每类 20 例） | 关校验全部出错 → 开校验 0 例到达用户 |
| 3 类异常（抛错、超时、空输出） | 开、关校验均能降级完成 |

**局限**：用例由作者自编；故障是人工构造的，衡量拦截能力，不代表真实模型的出错率；**尚未用真实大模型跑分**。留出集失败：1k5 写法、未收录磨损、两条滥用表达（落到追问，未给出做法）。数字溯源只检查数字是否出现过，不检查语义是否用对。
